DeskRat — некоммерческий форк [Forecastych/DeskPartner](https://github.com/Forecastych/DeskPartner), созданный в память о Пенни. Авторство исходного проекта сохранено.

## Что она умеет

- **Гуляет и дремлет** на панели задач, краях экрана и рамках окон. В середину экрана не лезет.
- **Ест** из миски, которую можно перетащить куда угодно, и проголодается через пару часов после еды.
- **Спит** на лежаке.
- **Обижается**, если её донимать, и это помнит.
- **Смотрит кино** вместе с вами и прячется во время звонков.
- **Следит** за лазерной указкой: зажмите один `Ctrl` на мгновение, и курсор станет красной точкой.
- **Играет с клубком** время от времени.
- **Говорит редко**: облачко раз в 10–30 минут, с фактом, заметкой «в этот день» или заголовком новости по выбранным темам.

Клики проходят сквозь всё, кроме самой Пенни, её миски, лежака и облачка. Фокус клавиатуры она не забирает, а пока игра или видео идут в эксклюзивном полноэкранном режиме, её нет.

Пенни не попадает на скриншоты и запись экрана (это можно поменять). То, что пошумнее, по умолчанию выключено и ждёт в настройках: лежак, кормушка, охота за курсором, новости, отзывы о фильмах.

## Установка

1. Используйте локально собранный `DeskRat_<версия>_x64-setup.exe` из `src-tauri/target/release/bundle/nsis/`. Релиз исходного DeskPartner — другое приложение.
2. Запустите. Ставится в профиль пользователя, права администратора не нужны.
3. При первом запуске дайте ей имя и выберите папку для её данных.

Работает на Windows 10 и 11.

> [!WARNING]
> **Windows SmartScreen будет ругаться на установщик.** Установщик не подписан: сертификат для подписи кода стоит денег каждый год, а это бесплатный проект для души. Чтобы всё равно установить, нажмите **Подробнее → Выполнить в любом случае**. Если не хочется доверять чужому exe, [соберите из исходников](#сборка-из-исходников), это пара команд.

**Обновления.** Автоматическая проверка и установка обновлений в DeskRat отключены. Новую локальную сборку устанавливают вручную.

Удалить можно через «Установленные приложения» в параметрах Windows. Папка с данными останется там, куда вы её положили; если не нужна, удалите руками.

## Управление

| Что | Как |
| --- | --- |
| Меню | Правый клик по Пенни или по значку в трее |
| Лазерная указка | Зажать один `Ctrl` или выбрать в меню (`Esc` выключает) |
| Кликнуть сквозь Пенни | Кликать с зажатым `Alt` |
| Спрятать / показать | `Ctrl+Alt+Shift+H` |
| Подозвать Пенни | ПКМ → трижды нажать «Пенни!» в одном меню; после третьего зова свободная Пенни подбежит |
| Ушла за край экрана | Трей → «Позвать питомца» |
| Настройки и статистика | Трей → «Настройки…» / «Статистика…» |

## Приватность

- **Ни аналитики, ни аккаунтов, ни телеметрии.**
- **Заголовки окон не читаются.** Единственное исключение: галочка про сайты в браузере: заголовок сверяется с вашим списком и сразу забывается.
- **Микрофон и камера не записываются.** Она только проверяет, заняты ли они, чтобы понять, что у вас звонок.
- **Экран не сохраняется.** Для лазера она смотрит на несколько пикселей в памяти, ничего не хранится и не отправляется.
- **Что уходит в сеть, и только когда функция включена:**
  - «В этот день» из Википедии: сегодняшняя дата и язык;
  - заголовки новостей: RSS-ленты выбранных тем (The Guardian, BBC и другие);
  - отзывы о фильмах: название фильма уходит в Wikidata и Википедию;
  - TMDB: только с вашим собственным ключом API.

Состояние хранится в выбранной папке в файлах `deskrat-*.json`; `%APPDATA%\DeskRat\location.json` содержит путь к ней. Данные DeskPartner хранятся отдельно.

Погоня за мышью отключена, её пунктов нет в меню и настройках. Клубок и лазерная указка доступны. Тройной зов не будит Пенни и не прерывает еду и другие занятия.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org/) (LTS), [Rust](https://rustup.rs/) и [то, что Tauri требует для Windows](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run app
```

`npm run app` запускает программу в режиме разработки. `npm run release` собирает установщик в `src-tauri/target/release/bundle/nsis/`.

Проверки:

```bash
npm run check
npm test
cd src-tauri && cargo test
```

Сделано на [Tauri 2](https://tauri.app/), Rust и [Svelte 5](https://svelte.dev/). Весь пиксель-арт нарисован в коде.
