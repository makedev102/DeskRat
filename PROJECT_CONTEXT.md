## Первичная безопасность — область и ограничения

- Проверены локальные npm/Cargo/build-скрипты, Tauri capabilities/IPC, файловые операции, shell-запуски, updater, типовые сигнатуры секретов. Это частичная статическая проверка и проверки зависимостей, не полный аудит и не доказательство отсутствия секретов в истории Git.
- Исправлены: совместные имена файлов/профиля, upstream-updater, затирание чужого `.probe`, общий предсказуемый tmp. Запись использует exclusive create_new и уникальный tmp; ошибки удаляют собственный tmp. Ссылки/reparse points в файлах состояния отклоняются; ключи ограничены известными именами. Откат копий при невозможности записать location.json; добавлены регрессионные тесты общей папки и ошибок переноса.
- В runtime-коде запуск shell/внешних программ не обнаружен; остаётся штатный перезапуск самого Tauri. Реестр Windows читается для определения созвонов. Capabilities локальные, remote origins не заданы; нет shell/fs/updater разрешений. CSP запрещает удалённые script/connect; текст сетевых ответов выводится средствами Svelte, без `@html`.
- Пользовательские IPC-команды доступны локальным окнам без разделения ролей; при будущем добавлении недоверенного UI потребуются ACL по окнам/командам. Защита от вредоносного процесса с теми же правами пользователя и файловых TOCTOU-гонок не заявляется.
- Подтверждённая зависимость: [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4), deepmerge 4.3.1, patched version отсутствует. Используется сборочным плагином для доверенной локальной конфигурации; эксплуатация приложением не подтверждена. Предложение отдельно: заменить/обновить зависимость после upstream-исправления; не применять npm audit fix --force вслепую.
- Введённый TMDB-ключ хранится открытым текстом в выбранной папке (`deskrat-settings.json`); встроенного ключа не найдено. Отдельное возможное исправление: Windows Credential Manager. Сетевые функции Wikipedia/RSS сохранены; их наличие не означает поддержку автообновлений.
